reates and opens the Modelfile in VS Code so I can configure my custom chatbot

FROM granite4:350m specifies the base model.
temperature 0.8 controls the creativity and variability of responses.
num_predict 150 limits the number of tokens generated.
SYSTEM defines the chatbot's personality and its three response rules.
